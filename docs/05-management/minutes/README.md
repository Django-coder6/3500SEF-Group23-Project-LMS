Minutes are recorded for every meeting. A decision that exists only in the
group chat is not a decision, so anything that matters is written here.

## File naming

A document that records something that happened on a particular day starts with
that date in `YYYYMMDD` form, so that a folder listing sorts itself
chronologically. This follows the rule in `CONTRIBUTING.md`.

```
docs/05-management/minutes/YYYYMMDD_short-description.md
```

Examples:

```
20261002_topic-selection.md
20261005_week1-standup.md
20261012_week1-summary-review.md
```

File names are lower case with hyphens. No spaces.

## What every set of minutes contains

| Section | Content |
|---|---|
| Header table | Date, time, chair, who took the minutes, attendees, absentees, related documents |
| Agenda | What was to be covered |
| Discussion | What was said, in enough detail that a member who missed it can catch up |
| Decisions | Numbered, each with the owner and, where it changes the project, the change record it maps to |
| Actions | What happens next, with an owner and a date each |
| Revision history | Version, date, change, author |

## Meeting rhythm

| Meeting | When | Purpose |
|---|---|---|
| Stand-up | Monday 20:00, 20 minutes | Each member says what they finished, what is next, and whether anything blocks them |
| Working session | Thursday 20:00, 45 minutes | Unblock anything that needs two or more people |
| Sprint review and retrospective | Last day of each sprint | Demonstrate the increment, then agree what to change |

Minutes for the stand-up may be short. Minutes for a sprint review must record
what the increment demonstrated, what the stakeholders said, and what the team
agreed to change.

## Recordings

Meetings may be recorded, for team members who cannot attend and for the
instructor on request.

Recordings are **not** stored in this repository. The repository holds text
sources so that a change shows as a readable difference, and a recording is a
binary file of tens of megabytes that cannot be reviewed. The location of a
recording is named in the minutes of that meeting, together with the access
rule and confirmation that attendees were told.

Where a recording is kept outside the repository, the minutes remain the record
of the meeting. A recording is evidence that the meeting happened; it is not
the minutes.
