## Illustrative requirement hypotheses (not findings from real users)

1. If real observations reveal lengthy waits or parcel searches, prioritize fast search and storage location tracking.
2. If residents raise proxy-pickup security concerns, consider time-limited, single-use, revocable authorization.
3. If staff describe peak-hour chaos, test barcode intake, handover logs, and exception management.
4. Validate all hypotheses against actual interviews and collected survey responses.
