# 3. Requirements Engineering

Requirements were elicited through four role-specific questionnaires (29 responses in total). The survey data directly shaped the product scope. The location recommendation feature was demoted from must-have to should-have because 0 of 7 staff respondents requested it (`CR-004`). Conversely, delegated collection was excluded from the must-have scope because 0 of 11 residents chose it (`CR-005`).

To ground these findings in user scenarios, composite personas and user journey maps were derived from the questionnaire data. The resulting Software Requirements Specification (SRS) defines 47 functional and 14 non-functional requirements, and the Requirements Traceability Matrix (RTM) confirms that every must-have requirement is mapped to a design artefact and a reserved test case.
